A WordPress theme for Torobche, a brand of colorable clothing for children.

== Description ==
This theme is designed to bring the vibrant and playful experience of the Torobche website to WordPress. It features a customizable hero section, a dynamic checkout page, and the same beautiful animations and glass morphism effects.

== Installation ==
1.  Download the `torobche.zip` file.
2.  In your WordPress admin panel, go to Appearance > Themes and click the "Add New" button.
3.  Click the "Upload Theme" button and choose the `torobche.zip` file you downloaded.
4.  Click "Install Now" and then "Activate".

== Usage ==
*   **Customizing the Hero Section:** Go to Appearance > Customize > Hero Section to change the images, titles, and subtitles of the slides.
*   **Setting up the Checkout Page:** Create a new page and select the "Checkout Page" template from the Page Attributes section.
*   **Menus:** Set up your primary menu under Appearance > Menus.
